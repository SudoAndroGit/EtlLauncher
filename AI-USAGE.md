# Uso de IA en EternalLauncher

En EternalLauncher se ha usado ChatGPT como apoyo durante el desarrollo para proponer y ajustar cambios de código, revisar parches y redactar documentación. Parte del código y de los textos de este repositorio se preparó con esa asistencia.

Este aviso se refiere al proceso de desarrollo del proyecto. El uso de IA no sustituye las pruebas del código ni la validación del instalador antes de publicarlo.

Si encuentras un error o quieres señalar un problema con alguna contribución, puedes abrir un [issue](https://github.com/WildMCs/EtlLauncher/issues).
