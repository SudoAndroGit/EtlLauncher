# Política de seguridad

## Alcance

Esta política cubre el código propio de EternalLauncher, sus parches, el proceso de compilación y los instaladores publicados en este repositorio. Indica la versión, el tag o el commit afectado para identificar la compilación.

## Reportar una vulnerabilidad

1. Ve a [Security → Advisories](https://github.com/WildMCs/EtlLauncher/security/advisories). Si GitHub muestra **Report a vulnerability**, usa ese formulario privado.
2. Si el formulario no está disponible, abre un [issue](https://github.com/WildMCs/EtlLauncher/issues/new) para pedir un canal privado de contacto. En ese issue incluye únicamente la solicitud de contacto. Guarda los detalles técnicos para el canal privado.
3. En el reporte privado, indica la versión afectada, el componente, el impacto y lo que observaste. Elimina tokens, credenciales y datos personales de los archivos adjuntos.

Para errores sin impacto de seguridad, usa la [plantilla de errores](https://github.com/WildMCs/EtlLauncher/issues/new/choose).
